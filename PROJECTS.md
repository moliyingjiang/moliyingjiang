# Public repository directory

[Profile · English](README.md) · [个人简介 · 中文](README.zh-CN.md) · [Academic project portfolio](https://blog.dengshu.cloud/projects.html)

This directory covers **23 public repositories**, with international access through GitHub and domestic access through Gitee. It distinguishes undergraduate research and engineering work from tools, archives, and current academic presentation. Current master's research is described in the [research record](https://blog.dengshu.cloud/research.html).

Upstream SDKs, detector baselines, compatibility adaptations, and resource collections are identified separately from project implementations. A repository link is not a claim of original authorship of its underlying framework.
