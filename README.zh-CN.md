目前就读于广西师范大学环境科学与工程专业硕士阶段，关注机器学习在环境数据分析、预测建模和模型解释中的应用，研究内容包括饮用水处理。本科就读于太原学院物联网工程专业，科研与工程实践主要涉及机器人感知与操作、计算机视觉及智能辅助诊疗。

这里记录当前研究与此前项目之间的联系。[个人学术主页](https://blog.dengshu.cloud/zh/)提供完整的研究记录和成长时间线；[公开仓库目录](PROJECTS.md)按研究实现、应用与竞赛、上游资源、展示与归档分类索引。
